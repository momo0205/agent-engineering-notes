## 核心问题

为什么逐步加噪、再学习逐步去噪的过程能够成为生成模型？DDPM 把生成写成一个有明确时间步的概率过程：正向过程逐渐扰动数据，反向模型学习在给定时间步时如何预测与去噪有关的量。本章先分清“前向加噪是怎样定义的”和“神经网络实际被训练来预测什么”。

## 论文背景与固定原文

原论文为 Jonathan Ho、Ajay Jain 与 Pieter Abbeel 的 *Denoising Diffusion Probabilistic Models*。本页固定链接 [arXiv:2006.11239v2 abstract](https://arxiv.org/abs/2006.11239v2) 和 [官方 PDF](https://arxiv.org/pdf/2006.11239v2)。阅读时请把论文中的概率符号、训练目标、采样过程和实验设置分段标注；“扩散模型会生成图像”并不能代替这些定义。

官方 PDF 由 arXiv 提供，本网站不镜像或重新分发。固定版本使学习记录可追溯，也让读者能判断后来版本或其他实现是否改变了讨论前提。

## 结构直觉

可以把前向过程看作不断加入受控噪声，最终得到接近简单噪声分布的变量；反向过程则需要在每个时间步依据当前带噪样本作出预测。小型实现常以预测噪声的方式组织训练目标，但“预测噪声”与“已经完整解释了变分目标”并不是一回事。

DDPM 与前两章的联系是叙事性的：去噪网络本身可以采用残差块，也可以在某些架构中加入注意力，以支持深层或长程信息交换。它们不是 DDPM 原论文本身给出的单线技术谱系，本章不会把这种关联写成因果结论。

## 最小复现

下面命令来自 [paper-deep-dive 固定提交](https://github.com/momo0205/paper-deep-dive/tree/2b8b41e63608725e6d4f25a44599014b1c22596e)。需要 Python 3.11；命令在 macOS 上显式使用 `python3`，并保留公开仓库 README 所列 smoke 的脚本路径和参数。它运行一个小型、离线的 DDPM smoke，用于检查基本数据流与脚本接口；它不是大规模图像生成训练，也不会下载数据集。

```bash
git clone https://github.com/momo0205/paper-deep-dive.git
cd paper-deep-dive
git checkout 2b8b41e63608725e6d4f25a44599014b1c22596e
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .
python3 code/ddpm/simple_ddpm.py --smoke --offline --output-dir /tmp/paper-deep-dive-ddpm
```

把输出目录、依赖版本、随机种子和参数一起保存，才有可能比较两次运行。发生错误时也保留错误：失败记录能区分环境问题、实现问题和还没理解的理论问题。
